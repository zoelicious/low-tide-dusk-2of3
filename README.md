# Low Tide

A dusk stealth game: a small otter pup slips home through the salt marsh before the tide returns. Hide in the reeds, ride the drifting cloud shadows, and stay out of the Grey Warden's bright yellow cone. Collect 3 shells, then reach the burrow.

- Top-down stealth: two named heron guards with learnable patrols (walk 4s, freeze 3s, head sweep 2s), vision cones, staged suspicion (CALM → UNEASY → SUSPICIOUS → HUNTED) with recovery.
- Signature mechanic: drifting cloud shadows — standing inside one counts as hidden.
- The tide returns at 4:00. Running is loud; walking is silent.
- Controls: WASD / arrows to move, SHIFT to run (loud), R to restart.

Play it: open `game/index.html` in desktop Chrome (no network, no build step). Screenshots in `screenshots/` are real renders of this code.

Built for the [best stealth game](https://make.fun/c/best-stealth-game-20261121-1759) competition on make.fun.
